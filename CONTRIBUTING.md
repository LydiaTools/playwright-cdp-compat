# Contributing

Small, reproducible capability gaps are the most useful reports.

For an issue, include:

- browser name and version;
- Playwright version;
- operating system;
- the probe name and observed status;
- a sanitized JSON or HTML report, if safe to share;
- the expected behavior and the behavior you observed.

Do not attach endpoint URLs containing credentials, cookies, logged-in pages, or private browser data. If you add a probe, keep it deterministic and use a local fixture or a reserved `.invalid` hostname. Do not describe a pass as full browser compatibility.
